Your data in the report page

The report page reads your files entirely in your browser. Nothing you drop on it - the report, or the geometry beside it - is uploaded to any server. Your files never leave your device, and the page works with no network connection at all once it has loaded.

Sharing an Organella report

A report is a parquet file holding what a run measured. Anyone you share it with can read all of it:

  • The base directory you processed is recorded in the report's footer metadata by default.
  • Object folder paths and volume names. Each row names the folder it was measured from and the label and mask files read out of it. If your folders or files are named after patients, samples or people, that is in the report.
  • Measurements. Voxel size, extent, and every per-structure, per-instance, distance and contact measurement the run took.
  • No pixel data. No image data and no thumbnails are written into a report. Surfaces and skeletons, when a run is asked for them, go into separate geometry.parquet files beside it - those describe the shape of what was segmented, not the image it came from.

If your data contains sensitive information, treat a report with the same care as the original data.

They are loaded because the page is one standalone file with no build step; nothing about your data is sent with the requests.
