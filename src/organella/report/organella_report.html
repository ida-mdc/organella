Organella

measuring label relationships in 2D and 3D

Make a report
pip install organella

organella dry-run experiment/
organella process experiment/ \
    -o report.parquet \
    --object-mask pm --with-mesh

dry-run reads headers only and says what would be measured. --object-mask names the mask that bounds each object, and everything inside it is measured relative to that. --with-mesh adds the geometry the 3D sections draw. Every flag is in the README.

Looking at a single

Drag to orbit, scroll to zoom, shift-drag to pan. Colour by structure to read the layout, by a metric to see where the extremes sit, or by contact group to see which instances chain together at a given gap. Explode pushes every instance out along its own direction from the centre.
