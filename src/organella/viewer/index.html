2Make a report 
pip install organella

organella dry-run experiment/
organella process experiment/ \
    -o report.parquet \
    --object-mask pm --with-mesh

dry-run reads headers only and says what would be measured. --object-mask names the mask that bounds each object, and everything inside it is measured relative to that. --with-mesh adds the geometry the 3D sections draw. Every flag is in the README.
